PRIVACIDAD DESDE EL PRIMER DÍA

La confianza se diseña.

Identidad, autorización y cifrado son capas distintas.

01

Tu cuenta

La versión final usará autenticación real y controles de acceso en el backend. Aquí solo existe un proveedor simulado.

02

Tus datos

Los registros se cifran en el dispositivo antes de almacenarlos en una nube simulada. El operador no necesita conocer los nombres de tus clientes.

03

Tu recuperación

La clave para recuperar información es independiente de la sesión. Si se pierde, una recuperación de login no basta para descifrar la bóveda.

Limitación importante: una PWA cuyo código puede cambiar el proveedor sigue expuesta a código comprometido o malicioso. Este proyecto necesita una revisión de seguridad antes de ofrecer garantías comerciales de cifrado extremo a extremo.
