SEGURIDAD

La confianza se diseña.

Distinguimos inicio de sesión, permisos y cifrado.

01

Cuenta

Supabase Auth verifica tus credenciales. Tu contraseña nunca se usa como la clave de tu bóveda privada.

02

Datos

Los registros profesionales se cifran en el navegador y se guardan como contenido cifrado. RLS impide el acceso entre cuentas.

03

Recuperación

Conserva la clave de recuperación. Una nueva contraseña de acceso no permite descifrar los datos si pierdes esa clave.

Esta beta no cuenta con auditoría E2EE externa. Una actualización maliciosa del código web o un dispositivo comprometido aún pueden poner en riesgo la confidencialidad.
